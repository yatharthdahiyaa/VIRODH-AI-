Attack demos use harmless “canary” payloads, or published benchmark images. The guard never sends harmful content to a model, even for comparison.

How it works

  1. Extract — read every text the model could see: OCR (incl. near-invisible text), QR codes, mirrored/rotated text, base64 and word-substitution tricks.
  2. Detect — injection, harmful content, cross-modal (prompt + image together), obfuscation.
  3. Decide — fuse the evidence into one risk score → ALLOW / REVIEW / BLOCK. Fail-safe: anything uninspected is held.
  4. Gate — only allowed requests reach the model; its reply is checked again.

    Adversarial image security …

    A separate engine that looks for adversarial pixel perturbations: image statistics, frequency analysis, prediction consistency on a local ResNet18 and localised anomalies. It reports suspicious image characteristics; it does not name the attack used, and results on the local ResNet18 are not evidence of an attack on the hosted VLM.

    Attack simulation (controlled)

    Controlled simulation against the local ResNet18 — not an attack on the hosted VLM. Generates an FGSM or low-iteration PGD perturbation of the selected image and shows whether it changed the local classifier's prediction, and whether the detector flags it.
